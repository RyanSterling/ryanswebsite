Below is a brain dump I dictated with my voice using Wispr Flow. Everything in it is how I actually talk. Turn it into a first draft of a short-form video script under [60] seconds.

EDITING RULES
Treat this as an edit, not a rewrite. Keep my exact words and phrases wherever you can. At least 80% of the script should be words I actually said.

You can:
- Cut repeated points, rambling, and tangents
- Reorder sections so the strongest idea comes early
- Join fragments so a sentence makes sense out loud

You can't:
- Add facts, stories, examples, or quotes I didn't say
- Swap my casual words for "better" ones
- Clean up my grammar if it's how I naturally talk
- Use short punchy sentence stacks, "It's not X, it's Y" lines, or a neat lesson at the end

SCRIPT FORMATTING
I don't use a teleprompter. I read one line, look at the camera, say it from memory, then look back down for the next line. The video gets cut together between lines. So:
- Put one spoken line per paragraph, with a blank line between each one
- Keep each line short enough that I can read it once and remember it, roughly 8 to 15 words
- Only break a line where a pause sounds natural out loud, like the end of a sentence or a clear clause. Never break in the middle of a thought, because the cut there will sound awkward
- If a sentence is too long to remember, split it at its most natural pause point instead of rewording it

ADDED LINES
Mark any line (or part of a line) in the script that you wrote yourself and that wasn't in my brain dump, so I can check it.

OUTPUT FORMAT
Give me everything as a single self-contained HTML page with a white background and easy-to-read text. Include these sections in order:

1. Legend: a small key showing that purple text with a dotted underline means words you added
2. Script: formatted using the Script Formatting rules above, with extra space between each line so it's easy to keep my place. Show any lines you added in purple text with a dotted underline
3. Cuts: a short list of the main points or lines you cut from my brain dump, so I can add any back
4. Estimated read-aloud time for the script
